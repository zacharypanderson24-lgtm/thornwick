# Crown & Hearth (Unity)

The Unity 6 port of Thornwick, the browser prototype at the root of this repository. The browser game stays untouched;
everything Unity lives in this folder.

- Editor: **Unity 6000.6.9f1**, URP 2D template, Input System. Open with `unity open unity` from the repo root (Unity CLI) or Unity Hub.
- Scene: `Assets/Scenes/Settlement.unity`. Press Play.

## Controls

Pan: WASD / arrows / right- or middle-drag. Zoom: mouse wheel (0.25x to 5x pixel ladder). Rotate: Q / E.
Space pauses; the top bar sets 1x / 2x / 4x (1 day = 1 second at 1x, as in the browser).
Tools: 1 Look, 2 Road (drag), 3 Housing, 4 Farmland, 5 Commerce, 6 Lumber, 7 Mining zones (drag to paint),
F Forester, X Sawmill, 8 Well, 9 Barracks, 0 Clear. Homes, farms, markets, woodcutter lodges, quarries and mines grow
by themselves on zones beside a road when there is demand (strip above the tool bar). Workers (bottom right) sets trade priorities.

## Layout

| Path | What |
|---|---|
| `Assets/Scripts/Sim` | The simulation as plain C# (no UnityEngine): terrain, buildings, roads, zones, workforce, daily tick. A port of `src/sim*.js`. |
| `Assets/Scripts/Game` | Unity side: isometric view and rotation, ground mesh, sprites, camera, HUD (uGUI), input. |
| `Assets/Scripts/Editor` | Menu **Crown & Hearth > Import Prototype Art** (reads `../assets`, keys out magenta, shrinks ground tiles to 32x16, draws `ph_*` placeholders) and **Rebuild Settlement Scene**. |
| `Assets/Resources/Art` | Imported sprites (generated by the importer; re-run it after changing `../assets`). |
| `Assets/Tests/EditMode` | Parity tests against the JavaScript sim. |
| `ParityReference` | `make_reference.js` runs the real browser sim and writes `reference.json` for the tests. |

## Parity with the browser game

The C# terrain is checked tile for tile against the JavaScript prototype (heights, forests and species, groves, rock, ore,
fertility, mountain elevations, starting settlement, housing and jobs) for two seeds, and zone development
(demand, every building grown, wood spent) over a 150-day scripted town:

```
node unity/ParityReference/make_reference.js     # from the repo root, after changing src/sim.js
unity test unity --mode EditMode                 # project must be closed in the Editor
```

## Not ported yet

- Walking work crews and townsfolk (`sim_crews.js`): crews are approximated by the same output per worker
  (0.8 logs, 0.7 stone, 0.55 ore a day), working the same marked tiles.
- Saves, the texture lab, banner tint, the info overlay (V).
- Art without files yet uses `ph_*` placeholders (farm, lodge, sawmill, forester, quarry, mine, market, well, rocks, ore, stump,
  sapling, and the 2x2 large house `manor_1`/`manor_2`, large farm `farm2` and bazaar `market2`). Drop real art into `../assets`
  with the slot name and re-run the importer; it takes precedence over the placeholder.
- Hills do not hide objects behind them yet (all ground draws before all objects).

## Working together

ChatGPT and Claude Code work on separate branches and merge into `unity-migration` through pull requests.
Scenes are tiny on purpose (everything is built in code), so they rarely conflict; avoid editing the same scene on two branches.
Art rules are unchanged: see `TEXTURE_SPEC.md` and `CHATGPT_START_HERE.md` at the repo root.

## Saving a settlement

**Save** writes one local slot. **Load** restores that slot and pauses the
settlement. On Windows the file is
`%USERPROFILE%/AppData/LocalLow/DefaultCompany/CrownAndHearth/thornwick-save-1.json`.

To import a browser settlement, back up any existing Unity slot. In the browser
where you played Thornwick, copy the raw value of `thornwick-save-1` from the
site's Local Storage in Developer Tools. Save that JSON to the path above, then
click **Load** in Unity. Old 40×40 and 64×64 settlements are centered on the
current 128×128 map.
