# Working on Thornwick

- The current Unity game lives in `unity/` on `unity-migration`. The repository root also contains the browser prototype.
- Before creating, revising, or reviewing textures, sprites, or animations, read [Thornwick texture style](TEXTURE_STYLE.md). It records the approved visual direction and how to check work in Unity.
- Use [Building tile guide](BUILDING_TILE_GUIDE.md) for footprint and rotation rules, and [Texture spec](TEXTURE_SPEC.md) for file formats and shared source-art conventions. The style guide distinguishes Unity-ready sprites from legacy source-art templates.
